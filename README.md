# Michelle's Next Chapter

A mobile-friendly guide to pathways from John A. Logan College to law school, legislative work, and public service.

## Features

- SIU Carbondale → Simmons Law accelerated 3+3 pathway
- UIS undergraduate studies → UIC Law accelerated pathway
- UIUC undergraduate study → Illinois College of Law
- Illustrative timeline and advising checklist
- Illinois Legislative Staff Internship Program
- Personal notes that save to local browser storage; copy/download options

## Publishing to GitHub Pages

1. Open the repository **Settings**.
2. Choose **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. After GitHub deploys, visit https://getoutmybelly.github.io/michelles-next-chapter/

The homepage is the root `index.html`, so no build step or external framework is necessary.

## Notes and privacy

Notes are stored with `localStorage` on the reader's device; there is **no server-side storage or shared comment feed**. Readers can copy or download their notes and share them intentionally. Browser storage may be cleared or unavailable.

## Accuracy

Academic timelines are illustrative. Program eligibility, transfer credit, tuition, financial aid and admission requirements must be verified with university advisors. Source links appear on the site.
